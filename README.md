# Simon Dice con Arduino Uno

## Descripción
Este proyecto consiste en una réplica del clásico juego Simon Dice utilizando un Arduino Uno. Su objetivo es poner en práctica los fundamentos de la programación en C++ y comprender el funcionamiento básico de un microcontrolador mediante el desarrollo de un proyecto interactivo.

## Componentes utilizados
- Arduino Uno
- 4 LEDs
- 4 pulsadores
- Resistencias
- Protoboard
- Cables Dupont
